# Foundations Checklist — Questions to Research

> Work through these questions. If you can answer them (and show a tiny demo), you’ve got the basics down.

## 0) Mental Model
- What is the **Python interpreter**?
- What’s the difference between a **module** and a **package**?
- What is `sys.path`?

## 1) System & Shell Basics
- What is a terminal and why do developers use it?
- What is the current working directory?
- What is the PATH environment variable?

## 2) Packages & pip
- What is a package/library and where do they come from (PyPI)?
- What is `pip`?
- How do you create a `requirements.txt`?

## 3) Virtual Environments
- What problem do virtual environments solve?
- How do you create, activate, and deactivate a `venv`?

## 4) Jupyter Notebooks
- What is a Jupyter kernel?
- When should you use `%pip install`?

## 5) IDE vs Notebook
- When is a notebook best vs a script/project?
- What is a good project structure?

## 6) Git & Collaboration
- Essential Git commands
- What belongs in a `.gitignore`?
